# Hi, I'm Avi Vajpeyi 👋

**Postdoctoral Research Fellow at the University of Auckland**

I develop scientific software for **Bayesian inference and noisy time-series analysis**, with applications to gravitational-wave astronomy.

## Selected projects

Some projects I've contributed to:

- **[LogPSplinePSD](https://github.com/nz-gravity/LogPSplinePSD)** — Bayesian estimation of power spectral densities and spectral matrices with NumPyro/JAX. [Paper](https://arxiv.org/abs/2607.04833)
- **[wdm-transform](https://github.com/pywavelet/wdm_transform)** — Wilson–Daubechies–Meyer time-frequency transforms for sampled signals, with NumPy and JAX backends. [Paper](https://arxiv.org/abs/2606.20269)
- **[TESS-Atlas](https://github.com/dfm/tess-atlas)** — Python tools for estimating exoplanet parameters from TESS observations.
- **[GlassRunner](https://github.com/kickflip-games/GlassRunner)** — A Unity/C# game our team built for Facebook Messenger. Regional winner, **Best Pre-Existing, Updated Solution**, [2019 Developer Circles from Facebook Community Challenge](https://devpost.com/software/glass-runner-6w1c0y).
- **[Blackwater](https://avivajpeyi.itch.io/blackwater)** — A Godot naval-combat game, made with the Kickflip Games team. [Source and credits](https://github.com/kickflip-games/ludum_dare_60)
